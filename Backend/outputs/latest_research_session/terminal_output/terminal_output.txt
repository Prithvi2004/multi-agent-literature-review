│  [P1] Efficient Transformers: A Survey                                                                │
│     Problem: The quadratic complexity O(n²) of the standard self-attention mechanism limits           │
│  application to long sequences.                                                                       │
│     Method: Survey and categorization of efficient transformer architectures into classes: fixed      │
│  patterns, learnable patterns, memory-efficient approximations, and low-rank approximations.          │
│     Results: Not Reported (Survey paper, no primary results).                                         │
│     Limitations: Many efficient approximations trade off global receptive field for computational     │
│  efficiency, which can harm performance on tasks requiring long-range dependencies. No single method  │
│  is optimal for all scenarios.                                                                        │
│                                                                                                       │
│  [P2] Linformer: Self-Attention with Linear Complexity                                                │
│     Problem: The quadratic complexity O(n²) of self-attention with respect to sequence length.        │
│     Method: Projects the key and value matrices into a lower-dimensional space using a fixed          │
│  projection, reducing complexity to O(n).                                                             │
│     Results: On the MNLI-m task, achieved an accuracy of 84.1% (standard Transformer: 84.6%).         │
│     Limitations: Performance is sensitive to the choice of projection dimension.                      │
│                                                                                                       │
│  [P3] Reformer: The Efficient Transformer                                                             │
│     Problem: High memory and computational cost of standard transformer attention.                    │
│     Method: Uses Locality-Sensitive Hashing (LSH) to approximate attention (complexity O(n log n))    │
│  and reversible residual layers to reduce memory usage.                                               │
│     Results: On image generation (Imagenet-64), achieved a bits per dimension (BPD) score of 3.65     │
│  (full attention: 3.57).                                                                              │
│     Limitations: LSH attention may not be as effective for tasks requiring very precise long-range    │
│  dependencies.                                                                                        │
│                                                                                                       │
│  [P4] MobileBERT: Task-Agnostic Compression of BERT                                                   │
│     Problem: Large size and computational cost of BERT.                                               │
│     Method: Uses a bottleneck structure and stacked feed-forward networks. Trained via                │
│  layer-by-layer knowledge distillation from a teacher BERT.                                           │
│     Results: On the GLUE benchmark, average score of 77.0 (teacher BERT: 78.3). On QQP, F1 score of   │
│  71.2.                                                                                                │
│     Limitations: Performance is highly dependent on the quality of the teacher model and the          │
│  distillation process.                                                                                │
│                                                                                                       │
│  [P5] DistilBERT, a distilled version of BERT                                                         │
│     Problem: Large size of BERT models.                                                               │
│     Method: Knowledge distillation during pre-training; student model is trained to mimic the         │
│  outputs of the full BERT model. Has 40% fewer parameters.                                            │
│     Results: On GLUE, retained 97% of BERT's performance (average score 76.6 vs. 79.0). On SST-2,     │
│  accuracy of 91.3%.                                                                                   │
│     Limitations: Distillation can lead to a loss of nuanced linguistic knowledge captured by the      │
│  larger model.                                                                                        │
│                                                                                                       │
│  [P6] ALBERT: A Lite BERT for Self-supervised Learning                                                │
│     Problem: Large parameter size of BERT models.                                                     │
│     Method: Factorized embedding parameterization (separating embedding size from hidden size) and    │
│  cross-layer parameter sharing.                                                                       │
│     Results: On GLUE, ALBERT-base average score 80.1 (BERT-base: 79.0). On RACE, accuracy of 67.4%.   │
│     Limitations: Parameter sharing might limit the model's representational capacity, potentially     │
│  leading to a performance ceiling.                                                                    │
│                                                                                                       │
│  [P7] Transformer Quality in Linear Time (FLASH)                                                      │
│     Problem: Quadratic cost of standard attention for long sequences.                                 │
│     Method: Gated attention unit combined with a linear recurrence, achieving linear complexity       │
│  O(n).                                                                                                │
│     Results: On PG-19 language modeling, perplexity of 22.4 (Transformer-XL: 22.1).                   │
│     Limitations: The gating mechanism may not capture complex dependencies as effectively as          │
│  standard attention in all cases.                                                                     │
│                                                                                                       │
│  [P8] A Survey on Efficient Training of Transformers                                                  │
│     Problem: High computational cost of pre-training large transformers.                              │
│     Method: Survey of efficient training techniques, including dynamic activation pruning,            │
│  mixed-precision training, and gradient checkpointing.                                                │
│     Results: Notes that gradient checkpointing can reduce memory usage by over 50% during training.   │
│     Limitations: Increased complexity of implementing and tuning these methods compared to standard   │
│  training.                                                                                            │
│                                                                                                       │
│  [P9] TinyBERT: Distilling BERT for Natural Language Understanding                                    │
│     Problem: Compression of BERT for efficient deployment.                                            │
│     Method: Two-stage distillation framework: general distillation during pre-training, then          │
│  task-specific distillation during fine-tuning.                                                       │
│     Results: On GLUE, 4-layer model average score 75.5 (~96% of BERT-base). On MRPC, F1 score of      │
│  88.5.                                                                                                │
│     Limitations: The framework's complexity requires careful orchestration of the two distillation    │
│  phases.                                                                                              │
│                                                                                                       │
│  [P11] FlashAttention: Fast and Memory-Efficient Exact Attention                                      │
│     Problem: High memory usage of standard attention implementations.                                 │
│     Method: IO-aware exact attention algorithm using tiling and recomputation to minimize GPU memory  │
│  reads/writes.                                                                                        │
│     Results: Achieved up to 3x faster training times for BERT-large on sequences of length 512.       │
│     Limitations: Speedup is most significant for long sequences and is hardware-dependent.            │
│                                                                                                       │
│  [P13] Prune Once for All: Sparse Pre-Trained Language Models                                         │
│     Problem: Large size of pre-trained transformers.                                                  │
│     Method: Applies magnitude pruning once to a pre-trained model to create a sparse mask; the        │
│  pruned model is fine-tuned for multiple tasks.                                                       │
│     Results: On SQuAD v1.1, pruned BERT-base (80% sparsity) F1 score 85.2 (dense model: 88.5).        │
│     Limitations: The pruning mask is fixed after initial pruning, which may not be optimal for all    │
│  downstream tasks.                                                                                    │
│                                                                                                       │
│  [P16] A Comprehensive Survey on Transformer Compression                                              │
│     Problem: Large size and computational demand of pre-trained models like BERT.                     │
│     Method: Survey of compression techniques: pruning, quantization, knowledge distillation,          │

│  loss (<1% drop on GLUE).                                                                             │

│  on target hardware.                                                                                  │
│                                                                                                       │
│  [P18] Efficient Long-Range Transformers: A Survey of Techniques and Benchmarks                       │
│     Problem: Poor scalability of transformers to very long sequences (>4000 tokens).                  │

│                                                                                                       │
│  The transformer architecture has revolutionized natural language processing, but its computational   │

│  into lightweight alternatives. This review synthesizes the evolution of efficient transformer        │
│  research from 2019-2023, covering architectural modifications, compression techniques, and           │
│  optimization methods. We identify three dominant paradigms: attention mechanism optimization (e.g.,  │
│  Linformer [P2], Reformer [P3]), model compression via knowledge distillation and pruning             │
│  (DistilBERT [P5], MobileBERT [P4]), and parameter efficiency through factorization (ALBERT [P6]).    │
│  Recent surveys [P1, P8, P16, P18] reveal that while significant progress has been made—with some     │
│  methods achieving near-linear complexity—fundamental trade-offs persist between computational        │
│  efficiency, model capacity, and task performance. The field is converging toward hybrid approaches   │

│                                                                                                       │
│  ## 1. Introduction & Motivation                                                                      │
│                                                                                                       │
│  The transformer architecture's self-attention mechanism, while powerful, exhibits O(n²) complexity   │
│  with respect to sequence length, making it computationally prohibitive for long sequences and        │
│  resource-constrained environments [P1]. This limitation has driven sustained research into           │
│  lightweight transformers that maintain competitive performance while reducing computational costs.   │
│  The motivation spans practical deployment needs (mobile devices, edge computing) and theoretical     │
│  interest in understanding which aspects of transformer architecture are essential for performance.   │
│                                                                                                       │
│  Early work focused primarily on reducing parameter counts through distillation [P5] and parameter    │
│  sharing [P6], while subsequent research targeted the attention mechanism itself [P2, P3]. More       │
│  recent approaches combine multiple strategies [P4, P22] and address specialized challenges like      │
│  long-range dependencies [P7, P18]. The evolution reflects a deepening understanding of transformer   │
│  internals and a recognition that efficiency requires holistic optimization rather than isolated      │
│  improvements.                                                                                        │

│  ## 2. Information Landscape: Methodological Taxonomy                                                 │

│  ### 2.1 Attention Mechanism Optimization                                                             │
│                                                                                                       │
│  The quadratic complexity of standard self-attention motivated fundamental architectural changes.     │
│  **Linformer** [P2] introduced linear complexity by projecting key-value pairs into                   │
│  lower-dimensional space, achieving 84.1% accuracy on MNLI-m compared to 84.6% for standard           │
│  transformers. However, performance proved sensitive to projection dimension choice. **Reformer**     │
│  [P3] used locality-sensitive hashing (LSH) to approximate attention with O(n log n) complexity,      │

│  potentially struggling with precise long-range dependencies.                                         │
│                                                                                                       │
│  **FLASH** [P7] advanced this line with gated attention and linear recurrences, achieving true        │
│  linear complexity while maintaining quality across diverse tasks. These approaches represent a       │
│  fundamental rethinking of attention computation, trading exact computation for scalable              │
│  approximations.                                                                                      │
│                                                                                                       │
│  ### 2.2 Model Compression Techniques                                                                 │
│                                                                                                       │

│  reduces model size, it may limit representational capacity, highlighting the inherent trade-off      │
